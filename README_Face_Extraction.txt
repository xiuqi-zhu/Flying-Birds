# Face Extraction from Videos

This project extracts faces from video clips using Haar Cascade and MTCNN face detection methods. It processes video clips listed in a CSV file, extracts 12 frames per video, detects faces, and saves them as images.

## Features
- Dual face detection using Haar Cascade and MTCNN for improved accuracy.
- Extracts and fills up to 12 frames per video clip.
- Saves extracted faces as resized images (224x224 pixels).
- Supports command-line arguments for input/output paths.
